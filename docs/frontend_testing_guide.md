# Frontend Testing & Simulation Guide

이 문서는 **Upstage AI Hackathon Business Track**을 위한 모바일 투자 대시보드 프론트엔드의 주요 기능과 각 페이지별 테스트 방법을 안내합니다. 모든 페이지는 백엔드 연동 없이도 테스트할 수 있는 **Simulation Mode**를 지원합니다.

---

## 1. 투자 페이지 (Invest Page)
사용자들이 실제로 팀을 확인하고 코인을 투자하는 메인 서비스 페이지입니다.

*   **접속 경로**: `/invest`
*   **테스트 방법 (Demo Mode)**:
    1.  접속 후 PIN 입력 창에 **`000000`** 입력.
    2.  보안 인증을 우회하여 데모 투자자 계정으로 진입.
*   **주요 확인 요소**:
    *   **팀 카드**: 실시간 주가 차트(Trend Chart) 및 펀딩 진행률 바(Progress Bar) 작동 여부.
    *   **투자 로직**: 타 학회 팀 투자 시 **1.2x 가중치**가 적용된 예상 가치 상승분 표시 확인.
    *   **밸런스 관리**: 투자 후 상단 헤더의 잔여 코인 및 원화 가치가 실시간으로 차감되는지 확인.

---

## 2. 관리자 페이지 (Admin Command Center)
행사 운영진이 시스템 전체의 상태를 제어하고 결산을 실행하는 전용 페이지입니다.

*   **접속 경로**: `/admin`
*   **인증 코드**: **`BOSS99`**
*   **주요 기능 테스트**:
    *   **Phase Control**: 'HALT' 클릭 시 `/invest` 페이지에서 투자가 차단되는지 확인.
    *   **Danger Zone**: 'FACTORY RESET' 클릭 시 모든 거래 내역이 초기화되는지 확인 (실제 운영 전 필수).
    *   **Settlement**: 'EXECUTE FINAL SETTLEMENT' 클릭 시 결과 페이지로 자동 전환되는지 확인.

---

## 2-1. 심사위원 페이지 (Judge Page)
심사위원이 팀별 점수를 입력하는 전용 페이지입니다.

*   **접속 경로**: `/judge?id=judge_01`
*   **추가 예시**:
    *   `/judge?id=judge_02`
    *   `/judge?id=judge_03`
*   **주요 기능 테스트**:
    *   팀 선택 후 AI Moat / BM Validity / Demo Completeness 점수 입력이 정상 동작하는지 확인.
    *   제출 후 점수 저장 성공 메시지가 표시되는지 확인.

---

## 3. 결과 발표 페이지 (Final Results)
행사의 하이라이트로, 최종 우승팀(The Unicorn)을 선포하는 시네마틱 페이지입니다.

*   **접속 경로**: `/results`
*   **시뮬레이션 모드**: `/results?demo=true`
*   **주요 확인 요소**:
    *   **Winner Reveal**: 1위 팀이 거대한 폰트와 글로우 효과와 함께 나타나는지 확인.
    *   **Final Leaderboard**: 우승팀 아래로 2~7위까지의 최종 합산 점수가 정렬되어 표시되는지 확인.

---

## 4. 럭키 드로우 (Unicorn Raffle)
우승팀에 투자한 기여자들을 대상으로 경품을 추첨하는 페이지입니다.

*   **접속 경로**: `/raffle`
*   **시뮬레이션 모드**: `/raffle?demo=true`
*   **주요 확인 요소**:
    *   **Weighted Draw**: 투자 금액이 많을수록 당첨 확률이 높게 설정된 가중치 풀 확인.
    *   **Draw Animation**: `ROLL THE RAFFLE` 클릭 시 사용자 ID가 빠르게 스캔되는 롤링 연출 확인.
    *   **Winner Display**: 최종 당첨자가 화려한 효과와 함께 공개되는지 확인.

---

## 💡 핵심 비즈니스 로직 참고
*   **1 Coin 가치**: ₩10,000,000 (천만 원)으로 고정 환산되어 UI에 표시됩니다.
*   **전략 지수 (Strategic Index)**: 타 학회(KU ↔ YU) 팀에 투자할 경우 투자 금액의 **1.2배**가 기업가치에 반영됩니다.
*   **최종 점수 산정**: `(시장 가치 점수 50점) + (심사위원 평균 점수 50점)`으로 합산하여 최종 순위를 결정합니다.
